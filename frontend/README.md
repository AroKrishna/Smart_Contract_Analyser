# Smart Contract Analyser — Frontend Application

This directory contains the React 19 + Vite + Tailwind CSS frontend application for **Smart Contract Analyser**.

## Scripts

- `npm run dev` — Launch Vite local development server on `http://localhost:5173/`
- `npm run build` — Compile and bundle production assets into `dist/`
- `npm run preview` — Locally preview the production build
- `npm run lint` — Run ESLint across all source files

## Architecture

- **React Router v7**: Complete SPA routing across all 10 application views
- **Tailwind CSS v4**: Modern styling with `@tailwindcss/vite`
- **Lucide React**: Clean enterprise icons
- **Recharts**: Data visualization primitives
- **Inter & JetBrains Mono**: Typography stack for UI and Solidity code
