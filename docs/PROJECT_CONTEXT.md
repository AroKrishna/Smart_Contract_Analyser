# Smart Contract Analyser

## Project Name
Smart Contract Analyser

## Project Type
Web-based AI SaaS application for analyzing Solidity smart contracts
for potential legal and compliance risks.

## Frontend
- React
- Vite
- JavaScript
- Tailwind CSS

## Application Purpose

The application allows users to upload or paste Solidity smart contracts
and receive an AI-assisted analysis of potential legal and compliance risks.

The frontend will eventually display:
- Overall risk score
- Risk categories
- Risk severity
- Confidence
- Highlighted contract sections
- SHAP explanations
- LIME explanations
- Recommendations
- Compliance information
- Audit reports

## Main Risk Categories

- Privacy
- Termination
- Legal Compliance
- Liability
- Payment / Financial

## Important AI Terminology
